# Overview Project

프로젝트 안에 로컬 코드 지도를 만들고, 파일 저장 시 갱신합니다. 공유할 때는 서버가 필요 없는 단일 HTML을 내보냅니다. Python, JavaScript/TypeScript/JSX/TSX, HTML, CSS의 구조와 정적으로 확인 가능한 연결을 표시합니다.

## 실행

Node.js 20 이상, pnpm, Python 3.9 이상이 필요합니다. Python 구문 버전은 설치된 Python이 지원하는 범위를 따릅니다. 도구 폴더를 Git으로 받은 뒤:

```sh
cd overview-project
pnpm install --frozen-lockfile
node cli/main.mjs serve /absolute/path/to/my-project
```

출력된 `http://127.0.0.1:4731`을 브라우저에 열어두고 작업합니다. Codex의 내장 브라우저에서도 같은 URL을 사용할 수 있습니다. 포트 충돌 시 `--port 0`으로 빈 포트를 할당합니다. `Ctrl+C`로 종료합니다.

`node`가 PATH에 없는 Codex 데스크톱 환경에서는 `python3 overview.py serve /absolute/path/to/my-project`를 사용할 수 있습니다. 이 실행기는 시스템 Node 또는 Codex가 제공하는 Node 런타임을 찾습니다.

```sh
node cli/main.mjs scan /absolute/path/to/my-project
node cli/main.mjs history /absolute/path/to/my-project
node cli/main.mjs serve /absolute/path/to/my-project --keep 100
node cli/main.mjs export /absolute/path/to/my-project
# 원하는 파일 이름(기존 파일을 덮어쓰지 않음)
node cli/main.mjs export /absolute/path/to/my-project --output ./review.html
```

`watch`는 `serve`와 같습니다. CLI 실행 파일을 PATH에 설치했다면 `overview-project serve .`로 호출할 수 있습니다. `OVERVIEW_PYTHON=/path/to/python3`으로 Python 실행 파일을 지정합니다.

## 프로젝트별 저장

```text
my-project/.overview-project/
├── .gitignore             # 생성물을 Git에서 제외
├── viewer/                # 분리된 HTML / CSS / JS
├── data/
│   ├── graph.json         # 현재 결과
│   └── history.json       # 로컬 버전 목록
├── tmp/
│   ├── cache/files.json   # 콘텐츠 해시 기반 파서 캐시
│   └── snapshots/         # 000001.json, 000002.json, ...
└── exports/               # 공유용 단일 HTML
```

버전은 각 프로젝트 복사본 안에서 독립적으로 증가합니다. 사용자별 업데이트 시점이 달라도 서로 동기화되지 않습니다. 분석 결과가 바뀔 때만 버전이 생기며 기본 최근 30개를 보관합니다. 스냅샷은 분석 결과이며 소스 복구 기능이 아닙니다. `tmp`를 지워도 원본은 보존되지만 이전 분석 이력은 복구되지 않습니다. 프로세스 강제 종료로 `tmp/scan.lock`이 남은 경우 실행 중인 스캔이 없는지 확인하고 빈 잠금 디렉토리를 제거하세요.

1.5초마다 파일 목록과 콘텐츠 해시를 검사하고 바뀐 파일만 다시 파싱합니다. 관계 연결은 전체 그래프를 다시 계산합니다. 현재 구현은 작은/중간 저장소를 위한 동기 분석이며 대형 저장소는 분석 중 UI 요청이 지연될 수 있습니다. 화면은 2초마다 결과를 확인합니다.

## 화면 사용법

1. **파일 구조**에서 폴더 그룹을 열고 파일을 펼칩니다. 클래스의 메서드는 클래스별로 묶이고, 연결된 그룹의 참조 배지로 다른 그룹을 탐색할 수 있습니다.
2. 함수를 선택하면 **코드 연결** 지도에 파일별 컨테이너와 코드 블록이 나타납니다. 블록은 소스 문서/관찰된 동작, 입력 파라미터, 반환식을 보여줍니다.
3. 블록의 **실제 코드 펼치기**로 코드를 읽고, **입출력·호출 상세**로 타입·기본값·반환 위치·호출 인수를 확인합니다. 코드 영역 안에서는 스크롤하고, 빈 캔버스는 드래그해서 이동합니다.
4. 다른 블록을 눌러도 기존 그래프와 위치가 유지됩니다. **+ 연결 N개 펼치기**는 새 노드를 누적해서 추가합니다. 더 추가할 노드가 없으면 초록색 **✓ 연결 펼쳐짐**으로 바뀌고 비활성화됩니다. 상단에 추가된 노드 수가 표시됩니다.
5. **전체 보기**로 그룹 화면에 돌아갑니다. `표시 대상` 필터는 유지되므로 전체 종류를 다시 보려면 필터도 `전체`로 바꿉니다.

### 표시 대상과 공유 변수

| 표시 대상 | 표시 내용 |
| --- | --- |
| 전체 | 현재 보기 모드에 해당하는 코드 요소 |
| 클래스만 | 클래스 정의 |
| 함수·메서드만 | 함수, 메서드, React 컴포넌트, 테스트 함수 |
| 모듈 전역변수 | 정적으로 확인한 모듈 수준 변수 |
| 공유 전역변수 | 서로 다른 함수·메서드 2개 이상이 읽거나 쓰는 모듈 변수 |

공유 전역변수 목록에는 사용자 함수와 읽기/쓰기가 표시됩니다. 변수를 누르면 변수와 사용 함수가 파일별 컨테이너 안에 배치되고 `reads`/`writes` 선으로 연결됩니다. `관계` 필터로 읽기 또는 쓰기만 좁힐 수 있습니다. 타입 필터는 파일 소속 정보를 없애지 않으며, 펼친 노드 일부가 필터에 의해 숨겨질 수 있습니다.

### 테스트·스타일·로컬 버전

- **테스트**: 테스트 정의/파일과 정적 참조 대상. 참조가 확인된 테스트 파일은 가장 많이 참조하는 모듈에 함께 표시됩니다. 실행 결과나 커버리지가 아닙니다.
- **스타일**: HTML/JSX의 정적 class 문자열과 CSS 선택자/유틸리티 사용.
- **분석 버전**: 과거 스냅샷을 선택합니다. 새 결과가 도착해도 과거 화면은 유지되며, `현재 버전 · Live`로 돌아갈 수 있습니다.
- **하단 차이**: 직전 분석 대비 추가·삭제·변경 노드와 관계 수. **Export HTML**은 현재 보고 있는 버전을 내보냅니다. CLI `export`는 최신 분석 결과를 내보냅니다.
- **확대/이동/Fit**: 빈 캔버스에서 휠로 확대/축소하고 드래그로 이동합니다. 현재 `Fit`은 원래 배율과 위치로 돌아가는 버튼이며 전체 그래프 맞춤 축소가 아닙니다.

함수 소스는 24,000자까지 저장하며 초과 시 상세에 생략 표시가 나옵니다. 함수 외 노드는 최대 40줄 미리보기를 사용합니다. 탐색 그래프는 누적 확장되므로 큰 프로젝트에서는 필요한 연결만 펼치세요. 모든 함수를 한 화면에 자동 축소하거나 대규모 그래프를 가상화하지는 않습니다. 연결선은 실행 순서가 아닙니다.

## 지원 범위와 제한

Python은 표준 AST로 구문을 분석합니다. Python 이름/호출 연결은 보수적 추정입니다. TypeScript 파서로 JS/TS와 JSX/TSX 선언 및 직접 호출/렌더 참조를 읽습니다. 상대 경로 import를 지원하지만 tsconfig paths, 복잡한 재수출, 동적 import, 동적 디스패치, 별도 언어 사이의 API 호출은 현재 해결하지 않습니다. React props/state의 완전한 데이터 흐름 분석은 포함되지 않습니다. 타입 검사 기반 해석이 아닌 연결은 추정으로 표시합니다.

HTML은 parse5, CSS는 PostCSS로 파싱합니다. CSS 선택자 클래스의 이름 일치는 적용 가능성만 나타냅니다. Tailwind는 정적 클래스 사용을 표시하며 설정 실행/유틸리티 유효성 검증은 하지 않습니다. HTML의 인라인 스크립트/스타일과 동적으로 구성한 클래스는 별도 분석하지 않습니다.

`.gitignore` 규칙, 일반 빌드/의존성 디렉토리, `.env*`, 심볼릭 링크를 제외합니다. 2 MiB를 넘는 소스는 알림을 남기고 건너뜁니다. 구문 오류는 파일별로 표시하며 나머지 파일 분석을 계속합니다. 원본 프로젝트를 import하거나 실행하지 않습니다.

역할 설명은 문서 주석을 근거로 합니다. 주석이 없으면 관찰된 호출/반환식만 표시하며 업무상의 의도를 추정하지 않습니다. 반환식과 인수는 실제 실행값이 아닙니다. 타입 추론·인수 바인딩·완전한 데이터 흐름, 콜백의 호출 소유권, 동적 속성/객체 변경 및 모든 이름 가림의 정확한 해석은 보장하지 않습니다.

단일 HTML은 분석 데이터·함수 소스·미리보기·뷰어를 포함하므로 오프라인으로 열 수 있습니다. 공유 전 포함된 소스와 민감 정보를 확인하세요. 로컬 서버는 loopback에만 바인딩하고 원본 파일을 임의 경로로 제공하지 않습니다.

## Codex 스킬

배포 폴더의 `skills/overview-project`를 Codex가 발견하는 개인 스킬 위치에 심볼릭 링크하면 `$overview-project`로 사용할 수 있습니다. 전체 도구 폴더와 `node_modules`는 함께 유지합니다. 예시(기존 경로가 없는 경우):

```sh
mkdir -p ~/.agents/skills
ln -s /absolute/path/to/overview-project/skills/overview-project ~/.agents/skills/overview-project
```

`.codex-plugin/plugin.json`도 포함되어 있습니다. 이 저장소는 플러그인 패키지를 제공하지만 개인 마켓플레이스에 자동 등록하지 않습니다. MCP 서버 없이 CLI와 브라우저를 이용합니다.

## 개발

```sh
pnpm test
node cli/main.mjs serve tests/fixtures/sample
```

분석기/저장 형식 변경 시 `ENGINE` 버전을 올려 캐시를 무효화합니다. `schema/graph.schema.json`은 뷰어와 분석기의 데이터 계약입니다.
